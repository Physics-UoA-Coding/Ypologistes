# Προγραμματισμός C, C++ και Fortran σε Windows με WSL και Ubuntu

## 1. Εισαγωγή

Το παρόν αποθετήριο αφορά το μάθημα **«Υπολογιστές»**, το οποίο διδάσκεται κατά το 2ο εξάμηνο σπουδών.

Σκοπός του αποθετηρίου είναι η συγκέντρωση και η ανταλλαγή εκπαιδευτικού υλικού σχετικού με το μάθημα. Μπορείτε να συνεισφέρετε προσθέτοντας σημειώσεις, παραδείγματα κώδικα, ασκήσεις και επεξηγήσεις, δίνοντας ιδιαίτερη έμφαση στην **κατανόηση της θεωρίας και της λειτουργίας του κώδικα**. Η προσέγγιση αυτή είναι ιδιαίτερα χρήσιμη, καθώς οι ασκήσεις των εργαστηρίων υπολογιστών παρέχονται από τους διδάσκοντες με τη μορφή έτοιμων scripts.

Η ενασχόληση με τη γλώσσα προγραμματισμού **Fortran είναι προαιρετική** και αποτελεί μια επιπλέον δυνατότητα εξοικείωσης με τον επιστημονικό προγραμματισμό.

Στις ενότητες που ακολουθούν παρουσιάζονται αναλυτικές οδηγίες για την εγκατάσταση και τη διαμόρφωση ενός περιβάλλοντος προγραμματισμού **C, C++ και Fortran** σε Windows, με τη χρήση του **Windows Subsystem for Linux (WSL)** και του **Ubuntu**.

Η συγγραφή, η μεταγλώττιση και η εκτέλεση των προγραμμάτων πραγματοποιούνται απευθείας από το τερματικό του Ubuntu, με τη χρήση του επεξεργαστή κώδικα Neovim.

## 2. Εγκατάσταση WSL και Ubuntu

### 2.1 Προαπαιτούμενα

Για την εγκατάσταση χρειαζόμαστε:

- Windows 11 ή συμβατή έκδοση Windows 10.
- Σύνδεση στο διαδίκτυο.
- Δικαιώματα διαχειριστή (Administrator).
- Υποστήριξη εικονικοποίησης από το σύστημα.

Το **Windows Subsystem for Linux (WSL)** επιτρέπει την εκτέλεση ενός περιβάλλοντος Linux απευθείας στα Windows, χωρίς να απαιτείται ξεχωριστή εγκατάσταση λειτουργικού συστήματος.

Στον παρόντα οδηγό χρησιμοποιούμε το **WSL 2**, το οποίο εκτελεί έναν πραγματικό πυρήνα Linux μέσα σε μια ελαφριά εικονική μηχανή που διαχειρίζονται αυτόματα τα Windows.

### 2.2 Εγκατάσταση WSL

Ανοίγουμε το **Windows PowerShell** με δικαιώματα διαχειριστή (*Run as Administrator*).

Εκτελούμε:

```powershell
wsl --install -d Ubuntu
```

Η εντολή εγκαθιστά τα απαραίτητα στοιχεία του WSL και τη διανομή Ubuntu.

Η διαδικασία ενδέχεται να διαρκέσει μερικά λεπτά. Εφόσον ζητηθεί, επανεκκινούμε τον υπολογιστή.

Με την ολοκλήρωση της εγκατάστασης, το Ubuntu εκκινείται και ξεκινά η αρχική διαμόρφωσή του.

### 2.3 Δημιουργία λογαριασμού Ubuntu

Κατά την πρώτη εκκίνηση εμφανίζεται:

```text
Create a default Unix user account:
```

Εισάγουμε ένα όνομα χρήστη, για παράδειγμα:

```text
Create a default Unix user account: chris
```

Στη συνέχεια ορίζουμε έναν κωδικό πρόσβασης:

```text
New password:
Retype new password:
```

**Σημείωση:** Κατά την πληκτρολόγηση του κωδικού δεν εμφανίζονται χαρακτήρες στην οθόνη. Πρόκειται για φυσιολογική συμπεριφορά του Linux.

Ο λογαριασμός Ubuntu είναι ανεξάρτητος από τον λογαριασμό Windows.

Κατά την αρχική διαμόρφωση ενδέχεται επίσης να εμφανιστεί ερώτηση σχετικά με την αποστολή ανώνυμων δεδομένων χρήσης στην Canonical:

```text
Would you like to opt-in to platform metrics collection (Y/n)?
```

Η επιλογή είναι προαιρετική και δεν επηρεάζει τη λειτουργία του περιβάλλοντος προγραμματισμού.

### 2.4 Έλεγχος εγκατάστασης

Από το PowerShell εκτελούμε:

```powershell
wsl --list --verbose
```

Ένα ενδεικτικό αποτέλεσμα είναι:

```text
  NAME       STATE           VERSION
* Ubuntu     Running         2
```

Η ένδειξη `VERSION 2` επιβεβαιώνει ότι το Ubuntu χρησιμοποιεί WSL 2.

Για να ελέγξουμε την έκδοση του ίδιου του WSL:

```powershell
wsl --version
```

## 3. Χρήση του Ubuntu μέσω PowerShell

### 3.1 Εκκίνηση του Ubuntu

Από το PowerShell εκτελούμε:

```powershell
wsl -d Ubuntu
```

Το τερματικό αλλάζει και εμφανίζεται μια γραμμή εντολών παρόμοια με:

```text
chris@ph:~$
```

Όπου:

- `chris`: το όνομα χρήστη του Ubuntu.
- `ph`: το όνομα του υπολογιστή (hostname).
- `~`: ο προσωπικός κατάλογος του χρήστη.
- `$`: υποδηλώνει ότι χρησιμοποιούμε λογαριασμό χωρίς δικαιώματα διαχειριστή για τις συνήθεις εντολές.

### 3.2 Έξοδος από το Ubuntu

Για να τερματίσουμε την τρέχουσα συνεδρία του Ubuntu:

```bash
exit
```

Εφόσον έχουμε εκκινήσει το Ubuntu μέσα από το PowerShell, επιστρέφουμε στο προηγούμενο περιβάλλον.

Η έξοδος **δεν διαγράφει τα αρχεία, τους μεταγλωττιστές ή τις ρυθμίσεις μας**.

Για να επιστρέψουμε στο Ubuntu, εκτελούμε ξανά:

```powershell
wsl -d Ubuntu
```

### 3.3 Μετακίνηση στον προσωπικό κατάλογο

Όταν εκκινούμε το Ubuntu από το PowerShell, ενδέχεται να βρισκόμαστε στον κατάλογο των Windows από τον οποίο εκτελέσαμε την εντολή.

Για παράδειγμα:

```text
chris@ph:/mnt/c/WINDOWS/System32/WindowsPowerShell/v1.0$
```

Για να μεταφερθούμε στον προσωπικό μας κατάλογο στο Linux:

```bash
cd ~
```

Ελέγχουμε την τρέχουσα τοποθεσία:

```bash
pwd
```

Αναμενόμενο αποτέλεσμα:

```text
/home/chris
```

Η εντολή `cd` (*change directory*) χρησιμοποιείται για τη μετακίνηση μεταξύ καταλόγων, ενώ η `pwd` (*print working directory*) εμφανίζει την πλήρη διαδρομή του τρέχοντος καταλόγου.

## 4. Διαχείριση αρχείων μεταξύ Windows και Ubuntu

Το WSL επιτρέπει την πρόσβαση τόσο στο σύστημα αρχείων του Linux όσο και στο σύστημα αρχείων των Windows.

### 4.1 Σύστημα αρχείων Linux

Ο προσωπικός κατάλογος του χρήστη βρίσκεται στη διαδρομή:

```text
/home/chris
```

Μπορούμε να μεταφερθούμε σε αυτόν με:

```bash
cd ~
```

Η αποθήκευση προγραμμάτων στο σύστημα αρχείων Linux προτείνεται όταν χρησιμοποιούμε εργαλεία ανάπτυξης του Ubuntu, καθώς προσφέρει εγγενή διαχείριση δικαιωμάτων Linux και γενικά καλύτερη απόδοση στις εργασίες του συστήματος αρχείων.

### 4.2 Σύστημα αρχείων Windows

Οι δίσκοι των Windows είναι προσβάσιμοι μέσα από το Ubuntu.

Για παράδειγμα, ο κατάλογος:

```text
C:\Users\chris\Documents
```

είναι συνήθως προσβάσιμος από το Ubuntu μέσω:

```text
/mnt/c/Users/chris/Documents
```

Για να μεταφερθούμε σε αυτόν:

```bash
cd /mnt/c/Users/chris/Documents
```

Η ακριβής διαδρομή εξαρτάται από το όνομα χρήστη και τη θέση του φακέλου Documents στα Windows.

Για να επιστρέψουμε στον προσωπικό κατάλογο του Ubuntu:

```bash
cd ~
```

### 4.3 Πρόσβαση στα αρχεία Ubuntu από τα Windows

Μπορούμε να ανοίξουμε τον τρέχοντα κατάλογο του Ubuntu στον Windows File Explorer με την εντολή:

```bash
explorer.exe .
```

Εναλλακτικά, από τη γραμμή διευθύνσεων του File Explorer μπορούμε να χρησιμοποιήσουμε:

```text
\\wsl$\Ubuntu\home\chris
```

Έτσι μπορούμε να διαχειριζόμαστε τα αρχεία του Linux και από το περιβάλλον των Windows.

**Για τις ανάγκες του παρόντος οδηγού, τα προγράμματα C, C++ και Fortran θα αποθηκεύονται στο σύστημα αρχείων του Ubuntu.**

## 5. Ενημέρωση του Ubuntu

Πριν εγκαταστήσουμε τους μεταγλωττιστές, ενημερώνουμε το Ubuntu.

### 5.1 Ενημέρωση λίστας πακέτων

Από το τερματικό του Ubuntu εκτελούμε:

```bash
sudo apt update
```

Η εντολή ενημερώνει τη λίστα των διαθέσιμων πακέτων από τα αποθετήρια λογισμικού.

### 5.2 Αναβάθμιση εγκατεστημένων πακέτων

Στη συνέχεια εκτελούμε:

```bash
sudo apt upgrade -y
```

Η εντολή εγκαθιστά τις διαθέσιμες αναβαθμίσεις των ήδη εγκατεστημένων πακέτων.

Η παράμετρος `-y` απαντά αυτόματα καταφατικά στις ερωτήσεις επιβεβαίωσης.

### 5.3 Η εντολή sudo

Η εντολή `sudo` επιτρέπει την εκτέλεση εντολών με αυξημένα δικαιώματα διαχειριστή.

Κατά την πρώτη εκτέλεση μιας εντολής `sudo`, το Ubuntu ενδέχεται να ζητήσει τον κωδικό πρόσβασης του χρήστη:

```text
[sudo] password for chris:
```

Εισάγουμε τον κωδικό που δημιουργήσαμε κατά την εγκατάσταση του Ubuntu.

Ο κωδικός δεν εμφανίζεται κατά την πληκτρολόγηση.

Μετά την επιτυχή ταυτοποίηση, το `sudo` διατηρεί συνήθως προσωρινά την εξουσιοδότηση, ώστε να μην απαιτείται επανεισαγωγή του κωδικού σε κάθε εντολή.

## 6. Εγκατάσταση εργαλείων προγραμματισμού

Για τη συγγραφή, τη μεταγλώττιση και την αποσφαλμάτωση προγραμμάτων C, C++ και Fortran θα χρησιμοποιήσουμε:

| Εργαλείο | Περιγραφή |
|---|---|
| GCC | Μεταγλωττιστής της γλώσσας C |
| GFortran | Μεταγλωττιστής της γλώσσας Fortran |
| G++ | Μεταγλωττιστής της γλώσσας C++ |
| Neovim | Επεξεργαστής κώδικα μέσω τερματικού |
| Git | Διαχείριση εκδόσεων και εγκατάσταση πρόσθετων |
| GNU Make | Αυτοματοποίηση της διαδικασίας μεταγλώττισης |
| GDB | Εργαλείο αποσφαλμάτωσης προγραμμάτων |

### 6.1 Εγκατάσταση

Από το τερματικό του Ubuntu εκτελούμε:

```bash
sudo apt install build-essential gfortran gdb neovim git -y
```

Το πακέτο `build-essential` περιλαμβάνει βασικά εργαλεία ανάπτυξης, όπως το GCC, το G++ και το Make.

### 6.2 Έλεγχος εγκατάστασης

Ελέγχουμε ότι οι μεταγλωττιστές έχουν εγκατασταθεί:

```bash
gcc --version
g++ --version
gfortran --version
```

Αντίστοιχα, ελέγχουμε το Neovim και το Git:

```bash
nvim --version
git --version
```

Κάθε εντολή εμφανίζει πληροφορίες σχετικά με την εγκατεστημένη έκδοση του αντίστοιχου προγράμματος.

Οι αριθμοί εκδόσεων ενδέχεται να διαφέρουν ανάλογα με την έκδοση του Ubuntu.

## 7. Δημιουργία καταλόγων εργασίας

Για την οργάνωση των προγραμμάτων μας θα δημιουργήσουμε έναν κεντρικό κατάλογο `Programming`, ο οποίος θα περιλαμβάνει τρεις υποκαταλόγους, έναν για κάθε γλώσσα.

### 7.1 Δημιουργία καταλόγων

Μεταφερόμαστε στον προσωπικό κατάλογο:

```bash
cd ~
```

```bash

```

Η εντολή `mkdir` (*make directory*) δημιουργεί νέους καταλόγους.

Η παράμετρος `-p` επιτρέπει τη δημιουργία των απαραίτητων γονικών καταλόγων, εφόσον δεν υπάρχουν ήδη.

### 7.2 Έλεγχος

Εκτελούμε:

```bash
ls Programming
```

Αναμενόμενο αποτέλεσμα:

```text
C  Cpp  Fortran
```

Η εντολή `ls` εμφανίζει τα περιεχόμενα ενός καταλόγου.

Η δομή των αρχείων μας θα είναι:

```text
/home/chris/
└── Programming/
    ├── C/
    ├── Cpp/
    └── Fortran/
```

### 7.3 Μετακίνηση στον κατάλογο Fortran

```bash
cd ~/Programming/Fortran
```

Επιβεβαιώνουμε τη θέση μας:

```bash

```


## 8. Neovim – Περιβάλλον ανάπτυξης κώδικα

Το Neovim είναι ένας ελαφρύς και παραμετροποιήσιμος επεξεργαστής κώδικα που λειτουργεί απευθείας στο τερματικό του Linux. Μπορεί να χρησιμοποιηθεί για την ανάπτυξη επιστημονικών και αριθμητικών εφαρμογών σε C, C++ και Fortran.

### 8.1 Βασικά πλεονεκτήματα

- Χρωματική επισήμανση της σύνταξης (syntax highlighting).
- Αυτόματη εσοχή ανάλογα με τη γλώσσα προγραμματισμού.
- Μικρή κατανάλωση υπολογιστικών πόρων.
- Ενσωματωμένο τερματικό με υποστήριξη διαδραστικής εισαγωγής δεδομένων.
- Προσαρμοσμένες συντομεύσεις πληκτρολογίου και παραμετροποίηση μέσω Lua.

### 8.2 Βασική χρήση

Ανοίγουμε ένα αρχείο με `nvim filename`. Αν δεν υπάρχει, δημιουργείται κατά την αποθήκευση.

| Πλήκτρο ή εντολή | Λειτουργία |
|---|---|
| `i` | Εισαγωγή κώδικα (Insert mode) |
| `Esc` | Επιστροφή στο Normal mode |
| `:w` | Αποθήκευση |
| `:q` | Έξοδος |
| `:wq` | Αποθήκευση και έξοδος |
| `gg=G` | Επαναπροσδιορισμός εσοχών σε ολόκληρο το αρχείο |

Οι εντολές που αρχίζουν με `:` ολοκληρώνονται με `Enter`.

### 8.3 Εγκατάσταση του Gruvbox

Το Gruvbox είναι ένα χρωματικό θέμα που βελτιώνει την αναγνωσιμότητα του κώδικα. Το εγκαθιστούμε με το Git, χωρίς να απαιτείται διαχειριστής πρόσθετων:

```bash
git clone https://github.com/morhetz/gruvbox.git ~/.local/share/nvim/site/pack/themes/start/gruvbox
```

### 8.4 Παραμετροποίηση του Neovim

Δημιουργούμε τον προσωπικό κατάλογο ρυθμίσεων και ανοίγουμε το αρχείο `init.lua`:

```bash
mkdir -p ~/.config/nvim
nvim ~/.config/nvim/init.lua
```

Πατάμε `i` και εισάγουμε την ακόλουθη παραμετροποίηση:

```lua
-- Editor settings
vim.opt.number = true
vim.opt.tabstop = 4
vim.opt.shiftwidth = 4
vim.opt.softtabstop = 4
vim.opt.expandtab = true
vim.opt.autoindent = true
vim.opt.mouse = "a"

-- Language-specific indentation and syntax
vim.cmd("filetype plugin indent on")
vim.cmd("syntax on")

-- Appearance
vim.opt.termguicolors = true
vim.opt.background = "dark"
vim.opt.cursorline = true
vim.g.gruvbox_contrast_dark = "medium"
vim.cmd("colorscheme gruvbox")

-- Save, compile and execute
local function compile_run()
    local ft = vim.bo.filetype
    local cmd

    if ft == "cpp" then
        cmd = "g++ -std=c++17 -Wall -Wextra -Wpedantic "
    elseif ft == "c" then
        cmd = "gcc -std=c17 -Wall -Wextra -Wpedantic "
    elseif ft == "fortran" then
        cmd = "gfortran -Wall -Wextra "
    else
        print("Unsupported programming language")
        return
    end

    vim.cmd("write")
    local file = vim.fn.shellescape(vim.fn.expand("%:p"))
    local exe = vim.fn.shellescape(vim.fn.expand("%:p:r"))
    cmd = cmd .. file .. " -o " .. exe

    vim.cmd("botright 12new")
    vim.cmd("terminal " .. cmd .. " && " .. exe)
    vim.cmd("startinsert")
end

vim.keymap.set("n", "<F5>", compile_run)
```

Αποθηκεύουμε με `Esc`, `:wq` και `Enter`. Οι ρυθμίσεις εφαρμόζονται κατά την επόμενη εκκίνηση του Neovim.

### 8.5 Αυτόματη μεταγλώττιση και εκτέλεση

Αφού γράψουμε ένα πρόγραμμα, πατάμε `Esc` και στη συνέχεια `F5`. Το Neovim αποθηκεύει τον πηγαίο κώδικα, επιλέγει τον κατάλληλο μεταγλωττιστή και ανοίγει ένα ενσωματωμένο τερματικό. Η εκτέλεση πραγματοποιείται μόνο εφόσον η μεταγλώττιση ολοκληρωθεί επιτυχώς (`&&`).

| Κατάληξη αρχείου | Μεταγλωττιστής | Πρότυπο |
|---|---|---|
| `.c` | GCC | C17 |
| `.cpp` | G++ | C++17 |
| `.f90` | GFortran | Προεπιλογή μεταγλωττιστή |

Στο ενσωματωμένο τερματικό μπορούμε να εισάγουμε δεδομένα σε προγράμματα που χρησιμοποιούν `scanf`, `std::cin` ή `read`. Για επιστροφή στο Normal mode του τερματικού πατάμε `Ctrl + \` και στη συνέχεια `Ctrl + N`. Με `:q` και `Enter` κλείνουμε το τερματικό πριν από την επόμενη εκτέλεση.

Η παραμετροποίηση αφορά αυτοτελή προγράμματα ενός αρχείου. Για μεγαλύτερες εφαρμογές με πολλαπλά αρχεία μπορούν να χρησιμοποιηθούν εργαλεία όπως το GNU Make.

Στις επόμενες ενότητες παρουσιάζεται και η χειροκίνητη μεταγλώττιση, ώστε να γίνει κατανοητή η διαδικασία που αυτοματοποιεί το F5.

## 9. Συγγραφή και εκτέλεση προγράμματος Fortran

Θα δημιουργήσουμε ένα απλό πρόγραμμα χρησιμοποιώντας αποκλειστικά το τερματικό του Ubuntu.

### 9.1 Δημιουργία αρχείου με Neovim

Από τον κατάλογο `Fortran` εκτελούμε:

```bash
nvim hello.f90
```

Η εντολή ανοίγει τον επεξεργαστή κώδικα Neovim.

Εφόσον το αρχείο `hello.f90` δεν υπάρχει, δημιουργείται κατά την αποθήκευσή του.

Η κατάληξη `.f90` χρησιμοποιείται για αρχεία πηγαίου κώδικα Fortran ελεύθερης μορφής (*free-form source*).

### 9.2 Συγγραφή προγράμματος

Πατάμε `i` και πληκτρολογούμε:

```fortran
program hello
    implicit none

    print *, "Hello from Fortran!"

end program hello
```

**Επεξήγηση:**

- `program hello`: δηλώνει την αρχή του κύριου προγράμματος.
- `implicit none`: απενεργοποιεί την αυτόματη δήλωση τύπων μεταβλητών και απαιτεί ρητές δηλώσεις.
- `print *`: εμφανίζει δεδομένα στην τυπική έξοδο.
- `end program hello`: δηλώνει το τέλος του προγράμματος.

### 9.3 Αποθήκευση και έξοδος από το Neovim

Για να αποθηκεύσουμε το αρχείο:

Πατάμε `Esc` και πληκτρολογούμε `:wq`, ακολουθούμενο από `Enter`.

### 9.4 Μεταγλώττιση με GFortran

Αφού επιστρέψουμε στο τερματικό, εκτελούμε:

```bash
gfortran -Wall -Wextra hello.f90 -o hello
```

Η εντολή μεταγλωττίζει τον πηγαίο κώδικα και δημιουργεί ένα εκτελέσιμο αρχείο με όνομα `hello`.

Οι παράμετροι έχουν την ακόλουθη σημασία:

| Παράμετρος | Περιγραφή |
|---|---|
| `gfortran` | Καλεί τον μεταγλωττιστή Fortran |
| `-Wall` | Ενεργοποιεί ένα σύνολο προειδοποιήσεων |
| `-Wextra` | Ενεργοποιεί επιπλέον προειδοποιήσεις |
| `hello.f90` | Αρχείο πηγαίου κώδικα |
| `-o hello` | Ορίζει το όνομα του εκτελέσιμου αρχείου |

Εφόσον δεν υπάρχουν σφάλματα, ο μεταγλωττιστής συνήθως ολοκληρώνει τη διαδικασία χωρίς να εμφανίσει κάποιο μήνυμα.

### 9.5 Εκτέλεση

Εκτελούμε:

```bash
./hello
```

Αναμενόμενο αποτέλεσμα:

```text
 Hello from Fortran!
```

Το `./` υποδηλώνει ότι το εκτελέσιμο αρχείο βρίσκεται στον τρέχοντα κατάλογο.

### 9.6 Έλεγχος αρχείων

Εκτελούμε:

```bash
ls -l
```

Ένα ενδεικτικό αποτέλεσμα είναι:

```text
-rwxr-xr-x 1 chris chris 16200 Nov 19 19:26 hello
-rw-r--r-- 1 chris chris    87 Nov 19 19:25 hello.f90
```

Παρατηρούμε ότι δημιουργήθηκαν δύο διαφορετικά αρχεία:

- `hello.f90`: το αρχείο πηγαίου κώδικα.
- `hello`: το εκτελέσιμο αρχείο που δημιουργήθηκε από τον μεταγλωττιστή.

Οι χαρακτήρες `r`, `w` και `x` αντιστοιχούν στα δικαιώματα ανάγνωσης (*read*), εγγραφής (*write*) και εκτέλεσης (*execute*).

Επομένως, το αρχείο `hello` διαθέτει δικαίωμα εκτέλεσης, σε αντίθεση με το αρχείο πηγαίου κώδικα.

## 10. Συγγραφή και εκτέλεση προγράμματος C

Η διαδικασία είναι αντίστοιχη με αυτή της Fortran, με τη διαφορά ότι χρησιμοποιούμε τον μεταγλωττιστή GCC.

### 10.1 Μετακίνηση στον κατάλογο C

Εκτελούμε:

```bash
cd ~/Programming/C
```

### 10.2 Δημιουργία αρχείου

Ανοίγουμε το Neovim:

```bash
nvim hello.c
```

Η κατάληξη `.c` χρησιμοποιείται για αρχεία πηγαίου κώδικα C.

### 10.3 Συγγραφή προγράμματος

Πατάμε `i` και πληκτρολογούμε:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello from C!\n");

    return 0;
}
```

**Επεξήγηση:**

- `#include <stdio.h>`: εισάγει τις δηλώσεις της βιβλιοθήκης τυπικής εισόδου και εξόδου.
- `int main(void)`: ορίζει την κύρια συνάρτηση του προγράμματος, χωρίς παραμέτρους.
- `printf()`: εμφανίζει κείμενο στην τυπική έξοδο.
- `\n`: εισάγει αλλαγή γραμμής.
- `return 0`: επιστρέφει την τιμή μηδέν, δηλώνοντας επιτυχή ολοκλήρωση του προγράμματος.

Πατάμε `Esc` και πληκτρολογούμε `:wq` και `Enter`.

### 10.4 Μεταγλώττιση με GCC

Εκτελούμε:

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic hello.c -o hello
```

Η εντολή δημιουργεί το εκτελέσιμο αρχείο `hello`.

Όπως και στη Fortran, οι παράμετροι `-Wall` και `-Wextra` ενεργοποιούν επιπλέον προειδοποιήσεις κατά τη μεταγλώττιση.

### 10.5 Εκτέλεση

```bash
./hello
```

Αναμενόμενο αποτέλεσμα:

```text
Hello from C!
```

### 10.6 Έλεγχος αρχείων

```bash
ls -l
```

Στον κατάλογο θα υπάρχουν τα αρχεία:

```text
hello
hello.c
```

Το πρώτο είναι το εκτελέσιμο πρόγραμμα και το δεύτερο ο πηγαίος κώδικας.

## 11. Συγγραφή και εκτέλεση προγράμματος C++

```bash
cd ~/Programming/Cpp
nvim hello.cpp
```

Πατάμε `i` και εισάγουμε:

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello from C++!\n";
    return 0;
}
```

Η βιβλιοθήκη `<iostream>` παρέχει λειτουργίες εισόδου και εξόδου, ενώ το `std::cout` χρησιμοποιείται για την εμφάνιση δεδομένων στην τυπική έξοδο.

Μπορούμε να πατήσουμε `Esc` και `F5` ή να αποθηκεύσουμε και να εξέλθουμε με `:wq` και να εκτελέσουμε χειροκίνητα:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic hello.cpp -o hello
./hello
```

Αναμενόμενο αποτέλεσμα:

```text
Hello from C++!
```

Οι παράμετροι `-std=c17` και `-std=c++17` επιλέγουν το αντίστοιχο πρότυπο της γλώσσας. Η `-Wpedantic` ενεργοποιεί πρόσθετες διαγνωστικές προειδοποιήσεις σχετικά με τη συμμόρφωση προς το πρότυπο.

## 12. Οργάνωση των αρχείων

Μετά την ολοκλήρωση των παραπάνω βημάτων, η δομή των καταλόγων μας είναι:

```text
/home/chris/
└── Programming/
    ├── C/
    │   ├── hello.c
    │   └── hello
    │
    ├── Cpp/
    │   ├── hello.cpp
    │   └── hello
    │
    └── Fortran/
        ├── hello.f90
        └── hello
```

Τα εκτελέσιμα αρχεία έχουν το ίδιο όνομα, αλλά βρίσκονται σε διαφορετικούς καταλόγους και επομένως δεν δημιουργείται σύγκρουση.

Για να επεξεργαστούμε ξανά ένα πρόγραμμα Fortran:

```bash
cd ~/Programming/Fortran
nvim hello.f90
```

Αντίστοιχα, για ένα πρόγραμμα C:

```bash
cd ~/Programming/C
nvim hello.c
```

Αντίστοιχα για τη C++ χρησιμοποιούμε `cd ~/Programming/Cpp` και `nvim hello.cpp`.

Μετά από κάθε αλλαγή στον πηγαίο κώδικα, πρέπει να πραγματοποιούμε εκ νέου τη μεταγλώττιση ώστε το εκτελέσιμο αρχείο να περιλαμβάνει τις αλλαγές.
